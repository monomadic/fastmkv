# fastmkv: native Matroska tag writer — plan outline

## 1. Scope
- **Does:** read and write Matroska `Tags`, leaving every other byte of the file alone.
- **Doesn't:** demux, remux, touch codecs, edit chapters or attachments. Codec support is irrelevant because clusters are never parsed, which is why rust-av/matroska's missing h264/hevc wouldn't matter here either.
- **Location:** standalone crate at `~/src/fastmkv` (the name looks free on crates.io), pulled into tagform as a path dependency. No dependencies beyond std.

## 2. EBML layer
- Variable-length integer read/write for element IDs and sizes.
- Element header walker: ID, size, payload offset.
- Top-level scan of the segment that skips over clusters by size rather than reading them.

## 3. File model
- Locate `SeekHead`, `Info`, `Tracks`, `Tags`, `Attachments`, `Cues`, `Void`.
- `Tags` parsed into `Tag { targets, simple_tags }`, nested `SimpleTag`s included.
- Unknown children kept as raw bytes so they round-trip.

## 4. Write strategy
1. **Fits in place:** new tags are no larger than old `Tags` plus adjacent `Void`. Overwrite, pad the remainder with `Void`.
2. **Doesn't fit:** append new `Tags` at the end of the segment, turn the old one into `Void`, update the `SeekHead` entry and the segment size.
3. **No `SeekHead` room:** write a new `SeekHead` into `Void` space, or refuse.

## 5. Refusals (clear errors, no write)
- Unknown-size segment (stream captures).
- Multiple segments.
- Segment size field too narrow to hold the new size.
- Anything that doesn't parse cleanly.

## 6. Safety
- The crate edits whatever path it's given; tagform calls it on a temp copy, verifies, then swaps, so invariant 3 holds.
- On APFS the copy can be a clone, so it costs nothing.
- Verify step: re-parse with fastmkv and cross-check with ffprobe (tags, stream count, duration).

## 7. API sketch
```rust
let mut f = fastmkv::open(path)?;
let tags = f.tags();               // read
f.set("TITLE", "…");               // global target
f.remove("COMMENT");
f.write()?;                        // in place on this path
```

## 8. Tests
- Unit: varint round-trips, header parsing, hand-built EBML buffers.
- Fixtures: generated by ffmpeg at test time, as in `tags/fixtures.rs`. Cases: no tags, tags with padding, tags without padding, attachment present.
- Property: every byte outside `Tags`/`SeekHead`/`Void`/segment size is identical before and after.
- `mkvpropedit` isn't installed here, so ffprobe is the only independent reader unless you install MKVToolNix for cross-checking.
